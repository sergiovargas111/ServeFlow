# ServeFlow

An AI coach and money tool for restaurant servers: log tips in seconds, see what a shift typically earns, plan your money, and learn your rights.

> Status: early development (Phase 0–1). See [`docs/PLAN.md`](docs/PLAN.md) for the roadmap.

## Getting started

```bash
npm install
cp env.example .env.local    # then fill in your keys
npm run dev
```

Open http://localhost:3000.
